# 🐾 노랑반 냥냥 출석 아일랜드

교실용 출석부 웹앱입니다. 학생이 자기 카드를 터치하면 냥이 뽑기 연출과 함께 출석 EXP를 받아요.

- **출석 EXP**: 마감 8분 이상 전 +200 👑 / 1분 이상 +100 💎 / 마감까지 +50 🐱
- **지각 EXP**: 1분 미만 -10 / 5분 미만 -50 / 10분 미만 -100 / 그 이상 -150
- 🥇🥈🥉 3등까지 메달, 🔥 연속 출석, 🎉 전원 출석 파티, 🐾 냥이 도감
- 📋 EXP 리스트: 항목을 누르고 학생을 골라 EXP를 더하거나 빼요
- 🧹 청소 당번: 그날 EXP 합계(출석 + EXP 리스트)가 마이너스인 학생
- 👋 이름 불러주는 인사말 50개, 🔥 연속 출석 도장
- ⏰ 1차·2차 알람, 📢 오늘의 알림, 📒 주·월·연 통계, 💾 백업 저장/불러오기
- 🏆 레벨 1~10: 시즌 EXP가 쌓이면 레벨 업! 레벨마다 꾸미기 아이템(새싹·리본·목도리·꽃핀·별핀·천사 날개·왕관·마법 모자·전설의 털빛)이 열리고, 학생이 🎨 꾸미기 방에서 색을 골라요 (기본 Lv.10 = 2200 EXP)
- 📋 종례하기: 버튼을 누르면 종례 내용이 화면 가득 떠요 (구글 시트 '종례' 탭에서도 작성 가능)
- 마스코트: 하나 🐱

## 💾 데이터는 어디에 저장되나요?

- 기본: 이 페이지를 연 **브라우저 안(localStorage)** 에 저장돼요. GitHub에는 화면(코드)만 올라가고 학생 명단·출결 기록은 올라가지 않아요.
- ☁️ **구글 시트 동기화**를 켜면 출석·EXP·청소·설정·알림이 선생님 구글 드라이브의 시트에 저장되고, 연결한 모든 컴퓨터에 자동으로 반영돼요(약 15초 간격).
- 알람 음원 파일만 용량 때문에 컴퓨터마다 따로 저장돼요.

## ☁️ 구글 시트 동기화 설정 (처음 한 번만)

1. [sheets.new](https://sheets.new) 에서 새 구글 시트를 만들고 이름을 정해요. 예: `냥냥 출석부 데이터`
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 원래 있던 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣은 뒤 💾 저장해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 을 골라요.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(내 계정 선택 → '고급' → '안전하지 않은 페이지로 이동' → 허용). 내가 만든 스크립트라서 뜨는 안내예요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
7. 출석부 ⚙️ 설정 → **☁️ 여러 컴퓨터 동기화** 에 붙여넣고 **🔗 연결하기**.
   - 첫 컴퓨터: 지금 데이터가 시트로 올라가요.
   - 다른 컴퓨터: 같은 주소를 넣고 **⬇ 시트 데이터 가져오기** 를 눌러요.

이후에는 시트의 **알림** 탭 / **종례** 탭 A2칸부터 한 줄씩 적으면 모든 화면에 떠요(휴대폰 구글 시트 앱도 OK).
`data` 탭은 출석부가 쓰는 칸이라 직접 고치지 마세요.

> 웹 앱 주소는 비밀번호처럼 다뤄 주세요. 주소를 아는 사람은 데이터를 읽고 쓸 수 있어요.

## 🔄 Apps Script 코드 업데이트하는 법 (가끔 필요할 때만)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 코드를 모두 지우고 최신 [`apps-script/Code.gs`](apps-script/Code.gs) 를 붙여넣고 💾 저장
3. **배포 → 배포 관리** → 연필(✏️ 수정) → 버전: **새 버전** → **배포**

웹 앱 주소는 그대로라서 출석부 설정은 다시 할 필요 없어요.
