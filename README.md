# 🐾 노랑반 냥냥 출석 아일랜드

교실용 출석부 웹앱입니다. 학생이 자기 카드를 터치하면 냥이 뽑기 연출과 함께 출석 EXP를 받아요.

- **출석 EXP**: 마감 10분 이상 전 +200 👑 레전드 / 8분 +150 🦄 유니크 / 5분 +100 💎 레어 / 2분 +50 🐱 노멀 / 마감까지 +20 🐾 세이프
- **지각 EXP**: 1분 미만 -10 / 5분 미만 -50 / 10분 미만 -100 / 그 이상 -150
- 🥇🥈🥉 3등까지 메달, 🔥 연속 출석, 🎉 전원 출석 파티, 🐾 냥이 도감
- 📋 EXP 리스트: 항목을 누르고 학생을 골라 EXP를 더하거나 빼요
- 🧹 청소 당번: 그날 EXP 합계(출석 + EXP 리스트)가 마이너스인 학생
- 👋 이름 불러주는 인사말 50개, 🔥 연속 출석 도장
- ⏰ 1차·2차 알람, 📢 오늘의 알림, 📒 주·월·연 통계, 💾 백업 저장/불러오기
- 🏆 레벨 1~10: 시즌 EXP가 쌓이면 레벨 업! 레벨마다 꾸미기 아이템(새싹·리본·목도리·꽃핀·별핀·천사 날개·왕관·마법 모자·전설의 털빛)이 열리고, 학생이 🎨 꾸미기 방에서 색을 골라요 (기본 Lv.10 = 2200 EXP)
- 👑 관리자 모드(비밀번호 잠금): 학생별 EXP 조정, 레벨 지정, 오늘 출석 변경, 모든 꾸미기 아이템 열기, 조정 내역 되돌리기
- 📋 종례하기: 버튼을 누르면 종례 내용이 화면 가득 떠요 (구글 시트 '종례' 탭에서도 작성 가능)
- 👩‍🎓 학생 페이지(student.html): 냥이 마을, 💬 우리 반 대화(귓속말 포함), 오늘의 알림·종례·청소 당번, 📮 질문·건의, 내 고양이 꾸미기(눈·입 색 포함), 알림 '확인했어요'
- 👩‍🏫 이름이 'OO쌤'이면 선생님 전용 인사 · 청소 당번/게이지/메달/통계 합계에서 제외
- 💬 대화 관리(관리자): 켜기/끄기, 귓속말 허용, 대화 시간(기본 07:00~22:00), 금지어, 학생별 쓰기 막기, 메시지 삭제, 선생님 메시지 보내기
- 마스코트: 하나 🐱

## 💾 데이터는 어디에 저장되나요?

- 기본: 이 페이지를 연 **브라우저 안(localStorage)** 에 저장돼요. GitHub에는 화면(코드)만 올라가고 학생 명단·출결 기록은 올라가지 않아요.
- ☁️ **구글 시트 동기화**를 켜면 출석·EXP·청소·설정·알림이 선생님 구글 드라이브의 시트에 저장되고, 연결한 모든 컴퓨터에 자동으로 반영돼요(약 15초 간격).
- 알람 음원 파일만 용량 때문에 컴퓨터마다 따로 저장돼요.

## ☁️ 구글 시트 동기화 설정 (처음 한 번만)

1. [sheets.new](https://sheets.new) 에서 새 구글 시트를 만들고 이름을 정해요. 예: `냥냥 출석부 데이터`
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 눌러요.
3. 원래 있던 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣은 뒤 💾 저장해요.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 을 골라요.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(내 계정 선택 → '고급' → '안전하지 않은 페이지로 이동' → 허용). 내가 만든 스크립트라서 뜨는 안내예요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
7. 출석부 ⚙️ 설정 → **☁️ 여러 컴퓨터 동기화** 에 붙여넣고 **🔗 연결하기**.
   - 첫 컴퓨터: 지금 데이터가 시트로 올라가요.
   - 다른 컴퓨터: 같은 주소를 넣고 **⬇ 시트 데이터 가져오기** 를 눌러요.

이후에는 시트의 **알림** 탭 / **종례** 탭 A2칸부터 한 줄씩 적으면 모든 화면에 떠요(휴대폰 구글 시트 앱도 OK).
`data` 탭은 출석부가 쓰는 칸이라 직접 고치지 마세요.

> 웹 앱 주소는 비밀번호처럼 다뤄 주세요. 주소를 아는 사람은 데이터를 읽고 쓸 수 있어요.

## 🔄 Apps Script 코드 업데이트하는 법 (가끔 필요할 때만)

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 코드를 모두 지우고 최신 [`apps-script/Code.gs`](apps-script/Code.gs) 를 붙여넣고 💾 저장
3. **배포 → 배포 관리** → 연필(✏️ 수정) → 버전: **새 버전** → **배포**

웹 앱 주소는 그대로라서 출석부 설정은 다시 할 필요 없어요.

## 👩‍🎓 학생 페이지 켜기 (v3)

1. 위 방법대로 **Apps Script 코드를 최신 Code.gs로 업데이트**하고 새 버전으로 배포해요.
2. 교실 TV 출석부 → ⚙️ 설정 → ☁️ 동기화 → **🔐 교사 열쇠**를 정하고 저장해요. (4글자 이상, 선생님 기기마다 같은 열쇠를 넣어요)
3. 👑 관리자 → **🔑 비밀번호 한꺼번에 만들기** → 나온 목록을 인쇄하거나 사진으로 남겨요.
4. ⚙️ 설정 → **🔗 학생용 링크 복사** → 반 단체방·클래스룸에 붙여넣어요.

- 학생은 링크로 한 번 들어오면 그다음부터는 `student.html`만 열어도 돼요.
- 학생 페이지는 공개 정보(이름·레벨·꾸민 고양이·알림·종례·청소 당번)만 받아요. 다른 친구 EXP·비밀번호·설정은 받지 않아요.
- 교사 열쇠가 없는 기기는 출석·설정·EXP를 바꿀 수 없어요. 학생은 비밀번호가 맞을 때 **본인 고양이 꾸미기와 알림 확인**만 할 수 있어요.
- 학생 비밀번호를 5번 틀리면 10분 동안 잠겨요.

> 개발 메모: `student.html`은 `python3 tools/build_student.py`로 만들어요. (index.html의 고양이 그림 코드를 그대로 가져와요)

## 🐾 냥코인 · 🏘️ 냥이 마을 (v5)
> Apps Script 코드를 **v6** 이상으로 바꾸고 **배포 관리 → ✏️ → 새 버전**으로 배포해야 해요.

- **냥코인**: 미션을 하면 코인을 받아요. 학생이 "완료했어요!"를 누르면 선생님이 👑 → 🐾 냥코인 관리에서 승인해요. 정시 출석 미션은 자동으로 지급돼요.
- **상점**: 쿠폰(선생님이 실물로 지급), 집(텐트·통나무집·오두막·성), 꾸미기(화분·쿠션·꽃·우체통·가로등·나무·분수).
- **냥이 마을**: 학생 페이지 → 냥이 마을 탭 → 🏘️ 마을 입장. 땅을 누르면 걸어가고, 이모티콘이나 말풍선을 쓸 수 있어요. 대화 가능 시간과 같은 시간에만 열려요. 교실 TV는 🏘️ 버튼으로 보기 전용 화면을 열 수 있어요.
- **게임 광장**: 가위바위보, 츄르 컵 찾기. 한 판에 최대 30코인, 하루 5판까지 할 수 있어요. 월·수·금은 08–15시, 화·목은 08–16시에 열려요(설정에서 바꿀 수 있어요).
- 미션 코인, 상품 가격, 게임 규칙은 모두 👑 → 🐾 냥코인 관리 → ⚙️ 설정에서 바꿀 수 있어요.
- **⏰ 쉬는 시간 해제 (v6)**: 👑 관리자 모드 → ⏰ 쉬는 시간 해제. 대화와 마을, 게임 광장을 시간 제한 없이 30분이나 1시간, 또는 밤 12시까지 열 수 있어요. 시간이 지나면 저절로 원래대로 돌아가요.
